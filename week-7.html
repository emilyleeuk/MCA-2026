For this week's task, I created a second version of my Week 5 MEI file and added additional metadata.

  • Genre: Piano sonata
  • Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)

I classified the piece as a piano sonata because this describes the musical form and instrumentation of the work. I chose the CC BY 4.0 licence because it allows my MEI encoding to be reused and adapted as long as appropriate credit is given.

Reflection

The metadata is currently displayed as unformatted text, which makes it difficult to read. I would improve the layout by separating information such as the title, composer, genre, catalogue number and licence into clearly labelled sections. I would also use CSS to add spacing and make the metadata match the style of the rest of my portfolio.
