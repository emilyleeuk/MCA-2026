MusicXML and MEI Comparison

1. Note

In MusicXML, a note is shown using a <note> element. Information such as pitch and duration is included inside it. MEI also uses a <note> element, but some information such as pitch can be stored using attributes like pname and oct.

2. Measure

Both MusicXML and MEI use a <measure> element to organise the music into bars. This means they represent measures in a fairly similar way.

3. Clef

MusicXML uses a <clef> element to describe the clef. MEI also stores clef information, but it can use slightly different attributes and structure.
