MusicXML and MEI Comparison

1. Note

In MusicXML, a note is represented using a <note> element, with information such as pitch and duration stored inside it. In MEI, a note is also represented using a <note> element, but information such as pitch can be stored using attributes such as pname and oct.

2. Measure

In MusicXML, each bar is usually represented using a <measure> element. MEI also uses a <measure> element to organise music into bars.

3. Clef

In MusicXML, clef information is stored using a <clef> element. MEI also records clef information, but the attributes and structure can be different.
