MusicXML and MEI Comparison

1. Note

In MusicXML, a note is represented using a <note> element, with information such as pitch and duration stored inside it. In MEI, notes are also represented using a <note> element, but information such as pitch can be stored using attributes such as pname and oct. This shows that the two standards can represent the same musical information in different ways.

2. Measure

In MusicXML, each bar is usually represented using a <measure> element, and the measure number can be stored as an attribute. In MEI, a bar can also be represented using a <measure> element. The two standards therefore use a similar structure for organising music into bars.

3. Clef

In MusicXML, the clef is described using a <clef> element with information such as the sign and staff line. In MEI, clef information can also be represented, but it may use different attributes and structures. This shows that both standards record the same musical feature in slightly different ways.
